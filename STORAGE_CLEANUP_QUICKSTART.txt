# ⚡ Storage Cleanup - Quick Start

## What This Does

Automatically deletes your **oldest posts** when storage gets close to the **1 GB free limit**.

Result: **FREE FOREVER** 💰

---

## 🚀 Setup (5 Minutes)

### 1. Install Firebase CLI
```bash
npm install -g firebase-tools
```

### 2. Initialize Functions
```bash
firebase init functions
# Select: JavaScript, No ESLint
```

### 3. Copy Function Code
```
Copy ALL content from: functions-storage-cleanup.js
Paste into: functions/index.js
```

### 4. Deploy
```bash
firebase deploy --only functions
```

### 5. Test
```bash
firebase functions:call getStorageStats
```

**Done!** ✅

---

## 🎯 How It Works

```
Every 24 hours:
  Check storage
  
  If > 900 MB:
    Delete oldest posts
    Until storage = 800 MB
    
  If ≤ 900 MB:
    Do nothing
    Keep all posts
```

---

## 📊 Configuration

Edit in `functions/index.js`:

```javascript
const STORAGE_THRESHOLD_MB = 900;  // Start cleanup at this
const STORAGE_TARGET_MB = 800;     // Delete until this
```

## 🧪 Commands

```bash
# Check storage now

```

## ✨ What Gets Deleted

**Deleted (Oldest First)**:
- Old posts from `newsPosts`
- Old posts from `meetingPosts`

**Never Deleted**:
- User accounts
- User profiles  
- Messages
- Other data

---

## 💡 Storage Thresholds

| App Size | Threshold | Target |
|----------|-----------|--------|
| Small (< 100 users) | 900 MB | 800 MB |
| Medium (100-1K users) | 950 MB | 850 MB |
| Large (1K+ users) | 980 MB | 900 MB |
