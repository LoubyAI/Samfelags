📞 TROUBLESHOOTING

Problem: "Permission denied" error
  → Check: 1) Are rules published? 2) Is user signed in?
  → Solution: Publish rules, then sign in

Problem: "Cannot read property 'firebaseFirestore'"
  → Check: Is firebase-firestore.js loaded in app.html?
  → Solution: Add script tag to HTML

Problem: "Unauthenticated" error
  → Check: Is user signed in?
  → Solution: Sign in first before calling Firestore

Problem: Real-time updates not working
  → Check: Did you call subscribeToCollection()?
  → Solution: Look at firestore-examples.js line ~100

Problem: Posts not appearing in Firestore Console
  → Check: Did rules get published?
  → Solution: Check Firebase Console > Firestore > Rules
