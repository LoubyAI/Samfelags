WHEN USER SIGNS UP:
  1. User enters age: 28
  2. Age group is NOT shown in form (removed)
  3. User submits
  4. System calculates: 28 → "26-35 ára" ✓
  5. System LOCKS it with timestamp ✓
  6. User redirected home

WHEN USER EDITS PROFILE:
  1. User clicks "Edit Profile"
  2. Age field appears GRAYED OUT (readonly)
  3. Warning message shows (yellow/warning color)
  4. Locked age group displayed: "26-35 ára"
  5. User can edit: name ✓, city ✓, bio ✓, interests ✓, photo ✓
  6. User CANNOT edit: age ✗ (readonly)

💾 DATABASE
