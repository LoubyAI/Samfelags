┌─ PROTECTION LAYERS ───────────────────────────────────────────────────────┐
│                                                                            │
│ LAYER 1: FRONTEND                                                        │
│ ─────────────────                                                        │
│ • Age field has readonly attribute in HTML                             │
│ • Visual feedback: grayed out/disabled appearance                      │
│ • Warning message explains the restriction                            │
│ • Prevents accidental changes                                         │
│                                                                        │
│ LAYER 2: BACKEND                                                      │
│ ────────────────                                                      │
│ • updateUserProfile() function checks ageGroupLockedAt                │
│ • Rejects age modifications if lock exists                            │
│ • Returns error: "Aldur getur ekki verið breytt eftir skráningu..."   │
│ • Allows other fields to be updated                                   │
│ • Secure even if user tries to bypass frontend protection             │
│                                                                        │
│ LAYER 3: FIRESTORE RULES (optional)                                   │
│ ────────────────────────────────────                                   │
│ • Security rules can enforce age lock                                  │
│ • Reject updates if age changed and ageGroupLockedAt exists           │
│ • Prevents database manipulation                                      │
│                                                                        │
